About this project

Built to demonstrate modern frontend engineering

ProcureAI is a portfolio frontend demonstration. The admin and supplier portals showcase interface design, navigation, and procurement-oriented workflows. Some data and interactions are simulated. Real-time synchronization, production authentication, enterprise integrations, and autonomous AI are not represented as implemented features.
